# Learning Roadmap

This roadmap is intentionally flexible. The goal is to build strong fundamentals while producing visible technical work.

## Stage 1 — Foundations

### Engineering
- University mathematics
- University physics
- Mechanics
- Basic electronics
- CAD

### Programming
- MATLAB
- Python
- Git / GitHub

### Embedded
- Digital logic
- Sensors
- STM / ESP fundamentals

## Stage 2 — Build & Analyze

- Write circuit-analysis notes
- Simulate simple circuits
- Automate engineering calculations
- Analyze sensor data
- Build small embedded-system exercises
- Improve CAD and mechanical-design fluency

## Stage 3 — Aerospace Transition

- Rocket fundamentals
- Flight mechanics
- Stability
- Propulsion fundamentals
- Avionics
- Control

Start converting theory into small simulations and design studies.

## Stage 4 — Research-Oriented Work

- Read papers regularly
- Reproduce selected results when possible
- Document assumptions and limitations
- Join undergraduate research / internships
- Develop a deeper aerospace specialty

## Documentation Goal

For each meaningful topic:

**Learn → Build → Verify → Explain → Publish**

The purpose of this GitHub is to make that cycle visible over several years.
