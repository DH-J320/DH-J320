## Note Template

Each note should ideally contain:

1. **What is it?**
2. **Why is it used?**
3. **How does it work?**
4. **Simple example**
5. **Common mistakes**
6. **Engineering application**
7. **What I still do not understand**

The aim is to convert passive studying into reusable technical knowledge.
