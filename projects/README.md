# Projects

This folder will contain progressively more complete engineering work.

## Current / Near-Term

### Circuit Analysis Notes
Generalized study material on analog/digital interface circuits and fail-safe logic.

**Possible outputs**
- Circuit diagrams made from scratch
- LTspice-style simulations
- Timing plots
- Short technical explanations

### MATLAB / Python Engineering Exercises
Small programs based on university mathematics and physics.

**Possible outputs**
- Linear algebra utilities
- Electric-field calculations
- Numerical simulations
- Plotting and data analysis

## Future Aerospace Projects

### Rocket Flight Simulation
Build a simple 1D/2D model and gradually add:
- Drag
- Atmospheric variation
- Variable mass
- Thrust curves
- Wind

### Rocket Stability Study
Study:
- Center of gravity (CG)
- Center of pressure (CP)
- Static margin
- Fin geometry

### Avionics / Flight Data
Long-term topics:
- Sensor acquisition
- Filtering
- Telemetry
- State estimation
- Flight computer architecture

## Project Rule

A project is not complete when the code runs.

It should also explain:
- the engineering question,
- assumptions,
- equations or logic,
- implementation,
- results,
- limitations,
- and the next improvement.
