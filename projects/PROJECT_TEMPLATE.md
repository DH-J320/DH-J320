# Project Title

## 1. Engineering Question

What problem am I trying to understand or solve?

## 2. Background

What theory, prior work, or engineering context is necessary?

## 3. Goal

Define a measurable target.

## 4. Assumptions

List assumptions explicitly.

## 5. Method

Explain the model, experiment, simulation, or implementation.

## 6. Implementation

Include:

- equations
- code
- circuit or mechanical design
- tools used
- parameters

## 7. Results

Show results with tables, plots, screenshots, or measured values when appropriate.

## 8. Verification

How did I check whether the result makes sense?

Examples:

- hand calculation
- datasheet comparison
- analytical solution
- independent simulation
- experimental measurement

## 9. Limitations / Failures

What does this work *not* prove?

What went wrong?

What assumptions may be weak?

## 10. Next Step

What should be improved next?

---

## Project principle

A project is not finished when the code runs or the CAD model looks complete.

It is finished when another person can understand:

**the question → the reasoning → the implementation → the result → the limitations.**
